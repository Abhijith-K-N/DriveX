# 🚗 DriveX — Premium Car Rental UI

A **production-ready luxury car rental interface** built with **Next.js 14 App Router**, **TypeScript**, and **Tailwind CSS**.  
DriveX provides a modern booking experience with premium UI, multi-step checkout, and persistent state management.

---

## ✨ Preview

DriveX simulates a **high-end car rental platform** where users can:

- Browse premium vehicles
- View detailed specifications
- Book cars through a multi-step flow
- Save favorites
- Manage bookings in a dashboard
